Твой рабочий ритм

Добавь проекты и задачи. У проектов можно менять прогресс, стоимость и статус оплаты; у задач — отмечать выполнение. Карандаш открывает редактирование.

Доход учитывает только оплаченные проекты по дате оплаты. Суммы проектов вводятся в рублях. Конвертер помогает пересчитать заказ из другой валюты, но не меняет стоимость проекта автоматически.

Календарь isDayOff учитывает российские праздники и переносы при пятидневной неделе. Остаток рабочих дней в верхней карточке относится к текущему месяцу и включает сегодня. Точки в календаре обозначают невыполненные задачи и незавершённые проекты с дедлайном.

Курсы поступают от CBR-XML-Daily — независимого сервиса с данными Банка России. Дата курса указана в карточке. Это справочный курс, а не курс покупки валюты в банке.

Оба API работают независимо. Если сервис недоступен, карточка покажет ошибку и кнопку повтора. Подставных данных нет.

Сохранение работает в этом браузере. Тема, свёрнутые карточки, проекты, задачи и таймер восстанавливаются после перезагрузки. Не очищай данные сайта, если хочешь их сохранить. Открывай сайт одним и тем же способом.

Как открыть: распакуй ZIP, оставь три файла в одной папке и открой index.html. Также можно открыть папку в VS Code и запустить index.html через Live Server. Установка Node.js не требуется. Для API нужен интернет.
