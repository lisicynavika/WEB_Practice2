# WEB_Practice2
Тема
Сайт для планирования проектов, задач, дедлайнов, рабочего времени и доходов. Есть производственный календарь, конвертер валют, прогресс проектов и светлая/тёмная тема. Пользовательские данные сохраняются в браузере через localStorage.
Запуск
1. Распаковать архив сайта.
2. Оставить index.html, style.css и java.js в одной папке.
3. Открыть index.html в браузере. Также можно запустить его через расширение Live Server в VS Code.
Для получения данных API нужен интернет. Установка Node.js и ключи API не требуются.
Два источника API
- isDayOff — рабочие, выходные и сокращённые дни в России. Запрос: https://isdayoff.ru/api/getdata?year=2026&month=10&cc=ru&pre=1. Год и месяц в коде подставляются автоматически.
- CBR-XML-Daily — курсы валют: https://www.cbr-xml-daily.ru/daily_json.js. Это независимый сервис, публикующий данные Банка России. При пересчёте учитывается номинал валюты; дата курса показана в карточке.
Каждая сетевая карточка отдельно показывает загрузку, результат или ошибку с кнопкой повтора. Ошибка одного API не останавливает остальные виджеты. Задачи и суммы проектов пользователь вводит самостоятельно.
Нейросеть
ChatGPT — подготовка HTML, CSS и JavaScript, подключение API и проверка расчётов. Заголовки оформлены шрифтом Advaken Sans Expanded из предоставленного архива.
Полезные промпты
1. «Создай дашборд фрилансера “Рабочий ритм” с проектами, задачами, дедлайнами и доходами. Подготовь index.html, style.css и java.js».
2. «Подключи isDayOff и CBR-XML-Daily независимо друг от друга. Для каждой сетевой карточки добавь загрузку, результат, ошибку и кнопку повтора. Не используй демонстрационные данные».
3. «Адаптируй панель для телефона и компьютера. Добавь переключение светлой и тёмной темы, сворачивание виджетов и сохранение пользовательских данных после обновления страницы».
